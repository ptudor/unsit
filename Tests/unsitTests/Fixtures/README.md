These redistributable synthetic archives were generated for RA6X-025 from the
bit recipes in review/2026/09/REVIEW_ASTRA6_XHIGH.md. They contain no private data.
The five preset and two shared/separate dynamic context fixtures must decode
to seven ASCII A bytes followed by B. No private archive or network is needed.

The three historical archives named in the project README are a separate corpus
gate. Their bytes and hashes were not supplied, so their historical comparison
cannot be reproduced or claimed by this suite. Record source SHA-256, member
paths, both fork SHA-256 values, lengths, and CRC outcomes when that corpus is
made available. The macOS 11 / Swift 5.7 minimum environment is also a separate
gate when unavailable; local tests record the actual host/toolchain.
