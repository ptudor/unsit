Unsit 1.0 opens classic StuffIt archives on macOS through a drag-and-drop app and
a command-line tool. Both restore native data and resource forks, Finder
metadata, and modification dates using the same extractor.

## Downloads

- `Unsit-1.0.0-macos-ARCH.dmg`: installer with an Applications shortcut.
- `Unsit-1.0.0-macos-arm64.zip`: app for Apple silicon, macOS 12 or later.
- `Unsit-1.0.0-macos-x86_64.zip`: app for Intel, macOS 12 or later.
- `unsit-1.0.0-macos-ARCH.tar.gz`: CLI, targeting macOS 11 or later.
- `unsit-1.0.0-source.tar.gz`: current source, tests, build scripts, and notices.
- `checksums.txt`: SHA-256 manifest for the release assets.
- `Unsit-1.0.0-macos-ARCH.update.json`: metadata used by the app's updater.

Open the installer or expand the app ZIP, then move Unsit to Applications. These builds use ad hoc
signatures and are not Developer ID signed or notarized. On a downloaded app,
macOS may require an explicit approval in Privacy & Security. Source builds are
also available; no command-line tool installation is needed to use the app.

## Recovery improvements

A private compatibility comparison recovered 1,095 members versus 290 with the
initial implementation, retaining all earlier fork bytes and file metadata. Of
the total, 56 members remain explicitly partial. Additional recovery does not
make damaged bytes trustworthy. Nonzero folder summary lengths are now accepted,
and trusted folder dates survive child extraction.

The app and CLI explicitly credit Unsit for files saved despite archive damage,
with complete and partial counts. Files found beyond damaged records use visible
recovery folders. Unsupported features and skipped validation are warnings without
being labelled bitrot. `--json` provides a structured extraction report.

## Updates

Stable app releases check GitHub daily by default. Choose **Unsit → Check for
Updates** to check immediately, select another interval, or disable automatic
checks. Installer downloads require matching byte counts and GitHub SHA-256
digests. Finish extracting and quit Unsit before dragging the new app into
Applications. Checks do not send archive contents or extraction reports.

## Implementation

The method-13 implementation is new MIT Swift code with bounded decoding and
documented numeric interoperability data. Both forks of exhaustive synthetic
preset probes match the external reference. Native tests also exercise malformed
input, dynamic tables, filesystem confinement, I/O faults, CLI actions, and the
app helper. See the verification document included in the source archive.

## Scope

Supports classic `SIT!` / `rLau` containers with methods 0 and 13. StuffIt 5 and
StuffIt X containers, encrypted forks, and other compression methods are outside
this release. Partial members and uncertain folder placement are clearly marked.
Version-specific archive count validation outside version 1 remains unverified
and produces a warning and nonzero status.

Published artifacts include source, MIT licensing, attribution notices,
checksums, and GitHub build attestations. Attestations identify the build source;
they do not provide Apple notarization or Developer ID signing.
