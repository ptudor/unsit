Unsit 1.2 speaks your language. The app's window, menus, alerts, status lines,
and update messages are now translated into 83 additional languages and
regional variants, and macOS chooses the one you use. Recovery itself is
unchanged from 1.0: the same extractor, the same forks, dates, and metadata.

## Downloads

- `Unsit-1.2.0-macos-ARCH.dmg`: installer with an Applications shortcut.
- `Unsit-1.2.0-macos-arm64.zip`: app for Apple silicon, macOS 12 or later.
- `Unsit-1.2.0-macos-x86_64.zip`: app for Intel, macOS 12 or later.
- `unsit-1.2.0-macos-ARCH.tar.gz`: CLI, targeting macOS 11 or later.
- `unsit-1.2.0-source.tar.gz`: current source, tests, build scripts, and notices.
- `checksums.txt`: SHA-256 manifest for the release assets.
- `Unsit-1.2.0-macos-ARCH.update.json`: metadata used by the app's updater.
- `Unsit-1.2.0-macos-ARCH.notarization.json`: accepted Apple submission IDs and final package hashes.

Open the installer or expand the app ZIP, then move Unsit to Applications. The
app and installers are Developer ID signed, notarized by Apple, and carry stapled
notarization tickets. A copy of Unsit 1.0 that checks for updates offers this
release; finish extracting and quit the old app before dragging the new one into
Applications.

macOS picks the language from **System Settings → General → Language &
Region**, either the system language or a per-app choice under Applications.
Counts use each language's own plural forms, and Finder shows the "Classic
StuffIt archive" file kind and the About window's copyright line in the chosen
language. The app's name, Unsit, is the same everywhere.

Still English in every language: the command-line tool and its diagnostics
in the Details sheet, the `(extracted)` folder suffix, and the Help page.
Translations are produced outside the repository; report a wrong or awkward
translation as an issue naming the language and the text, and see
`docs/localization.md` in the source archive for how strings are managed.

## Implementation

Every user-facing string goes through String Catalogs with translator comments,
and the release build compiles them into the app with `xcstringstool`.
`scripts/check-localization.py`, run by `make check` and CI, keeps the source
and catalogs in step in both directions, checks every translation's format
arguments against its key, and requires every bundled language to carry every
table so the app never mixes languages. Release verification checks the same
in the finished packages. The update sheet's "Check" menu is now labelled
"Check frequency".

## Scope

Supports classic `SIT!` / `rLau` containers with methods 0 and 13. StuffIt 5 and
StuffIt X containers, encrypted forks, and other compression methods are outside
this release. Partial members and uncertain folder placement are clearly marked.
Version-specific archive count validation outside version 1 remains unverified
and produces a warning and nonzero status.

Published artifacts include source, MIT licensing, attribution notices,
checksums, and GitHub build attestations. Attestations identify the build source;
Apple signatures and notarization are verified separately. The source archive
includes `RELEASE.md` with the complete repeatable release procedure.
